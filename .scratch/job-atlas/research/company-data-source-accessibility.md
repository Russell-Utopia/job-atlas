# 企业数据来源真实可访问性核验

核验时间：2026-08-28。本报告只依据平台运营方、市场监管部门和政府开放数据平台的一手资料；没有把“网页可以人工搜索”推断成“存在可稳定自动扫描的接口”，也没有重新采集福州、长沙样本数据。

## 结论

| 来源 | 按区域发现未知企业 | 补全已知企业身份 | 第一版定位 |
|---|---|---|---|
| 企查查开放平台 | **不能确认可完整扫描。**“企业模糊搜索”接受地址等关键词，但每次最多返回 5 条；官方文档未提供城市、行政区、经纬度、地图范围或园区过滤参数，也没有承诺地址关键词能穷举区域内企业 | **明确支持。** 可按企业名称或统一社会信用代码查询工商照面信息 | 取得企业实名认证、应用场景审核和付费额度后，作为可选的 `CompanyLookupSource`；不作为 `AreaCompanySource` |
| 天眼查开放平台（商业来源对照） | **不能确认可完整扫描。**官方只确认按关键词返回企业列表，没有找到可证明地图范围或园区穷举能力的接口资料 | **明确支持。** 可按公司名称、平台 ID、注册号或统一社会信用代码查询 | 需购买并接受严格内部使用限制，可作为企查查的替代增强来源；不作为默认必扫来源 |
| 国家企业信用信息公示系统公众网站 | **不支持作为自动化 Adapter。**公众功能是实名网页查询；名称关键词一次最多展示 100 条，不是公开机器接口 | **只能确认人工网页查询。**未找到面向普通开发者申请、带稳定契约的全国公开 API | 仅作为人工核验或证据来源，不进入自动扫描范围 |
| 国家公示系统的数据接口/批量共享 | 官方资料确认接口存在，但主要向其他政府部门、监管系统或审批后的开放共享提供 | 技术上具备数据核验能力，但 Job Atlas 当前没有可申请的通用公众凭证 | 需要政府合作或专项审批，当前不可用 |
| 地方政府开放数据平台 | 能力取决于具体城市、具体目录；有的平台确实提供需申请的企业数据 API，但不能据此推断全国或目标城市都可用 | 若当地目录包含企业基本信息，可支持 | 逐城市验证后再做可选 Adapter；不能成为跨城市默认必扫来源 |

因此，**企查查、天眼查和政府企业数据都不应成为 Job Atlas 第一版默认必扫来源**。商业 API 能解决的是“已有企业候选后的身份补全”，而不是“给定地图范围，证明已经找完所有企业”。第一版的 `RegionalCompanyDiscovery` 必须依赖另一个已经验证可按地图范围结束扫描的 `AreaCompanySource`；企业数据 API 只能在模块内部增强 `CompanyInfo`。

## 1. 企查查开放平台

### 1.1 访问条件

企查查确实有运营方提供的正式开放平台和 JSON API，不需要抓取企查查网页。其[开放平台首页](https://openapi.qcc.com/)给出的接入流程是注册账号、完成企业认证、申请开通服务、在线测试并接入业务系统。具体接口页面同时标注“限企业实名用户使用”和“需提供应用场景审核”。

调用需要 `APPKEY`、`SecretKey`、秒级时间戳和由三者生成的 MD5 Token；[官方常见问题](https://openapi.qcc.com/services/after/faq)说明 Key 在验证绑定手机号后取得，支持配置 IP 白名单，所有有效请求收费，购买的接口次数或余额有效期为两年。

价格会变化，以下只是核验日页面状态：

- [企业模糊搜索 ApiCode 886](https://openapi.qcc.com/dataApi/886)标价 0.10 元/次，页面列有 20 次免费试用和付费次数包。
- [企业工商信息 ApiCode 410](https://openapi.qcc.com/dataApi/410)标价 0.20 元/次，同样要求企业实名和应用场景审核。

这意味着它是**需要企业主体、审核和持续付费额度的商业依赖**，不是拿一个个人网页账号就能稳定调用的公共数据源。

### 1.2 区域发现：只够召回，不足以证明扫描完成

[企业模糊搜索](https://openapi.qcc.com/dataApi/886)支持把企业名、人名、产品名、地址、电话或经营范围作为一个 `searchKey`，可分页，并返回企业名称、法定代表人、登记状态、成立日期、注册地址、统一社会信用代码等；但官方说明每次请求最多返回 5 条。

它没有公开以下结构化查询参数：

- 城市或行政区代码；
- 经纬度、半径或多边形；
- 园区 ID 或园区边界；
- 用于证明某个地图范围已经穷举完成的空间分页游标。

因此可以把“长沙某园区名”或地址文字放入关键词以召回若干企业，但不能证明结果覆盖园区内所有企业。官方资料也没有承诺地址关键词搜索的查全率。企查查 886 **不满足** `MapArea -> CompanyInfo[]` 的完成性要求，不能实现第一版 `AreaCompanySource`。

### 1.3 已知企业核验：能力明确

[企业工商信息](https://openapi.qcc.com/dataApi/410)接受企业名称或统一社会信用代码，并返回企业名称、登记状态、统一社会信用代码、注册地址、省份、成立日期、企业类型、经营范围、登记机关和曾用名等字段。

Job Atlas 实际只需保存其中的最小子集：

- `name`：确认后的企业名称；
- `creditCode`：有值时作为稳定登记标识；
- `status`：登记状态；
- `address` 与 `province`：用于排除同名主体、关联地图候选；
- `originalNames`：只在解释简称或旧称时使用；
- 来源与查询时间：证明身份信息从哪里得到。

这些字段足以增强 `CompanyInfo`，不需要购买或保存股东、实际控制人、司法风险等与岗位发现无关的数据。[备案网站查询 ApiCode 515](https://openapi.qcc.com/dataApi/515)还能按企业名称或统一社会信用代码返回备案网站和域名，可作为后续官网候选，但仍需按照既定的一手证据门槛确认当前官网，不能直接等同于官方招聘来源。

### 1.4 自动化与许可边界

正式 API 本身就是允许自动调用的产品，但只能在已开通接口、有效额度和审核场景内使用。官方文档确认了计次收费、鉴权和 IP 白名单；**没有在当前可读取的开放平台公开页面中确认**以下事项：

- Job Atlas 可以保存接口结果多长时间；
- 能否把原始工商字段转售或对外再分发；
- 是否允许把返回数据用于训练模型；
- 单接口的固定每分钟频率上限。

这些不能自行推断，应在购买前向企查查取得适用于 Job Atlas 场景的书面合同或授权条款。第一版即使接入，也只保存上述最小内部身份事实，不把企查查原始数据加入对外 `Job`。

## 2. 其他商业企业数据：天眼查对照

天眼查同样有运营方提供的[开放平台 API 目录](https://open.tianyancha.com/api_list)：搜索接口按关键词返回企业列表；企业基本信息接口按公司名称或 ID 返回名称、成立日期、经营状态、注册资本、法定代表人、工商注册号和统一社会信用代码等。调用文档使用 `Authorization: token`，接口按次付费。

这证明“商业企业数据 API”不是企查查一家独有，但没有改变能力边界：当前官方目录只确认关键词企业搜索，未确认按城市、行政区、经纬度或园区穷举所有企业，所以它也只适合已知候选核验或模糊召回。

天眼查的[API 用户协议](https://open.tianyancha.com/property/protocol)还明确规定：

- API 数据仅限签约用户内部使用，不得向子公司、客户、供应商等其他主体销售、提供或许可使用；
- 默认调用频率上限为每分钟 1000 次，同时禁止不合理的大批量获取；
- 数据需在中国大陆范围内存储和使用，不得向境外传输；
- 账号和 Token 不可转让，平台可按约收回；
- 协议外的网页机器抓取、复制或镜像不属于正常 API 使用方式。

因此，即使购买天眼查，也必须确认 Job Atlas 的部署主体、调用目的和结果使用方式符合合同；它适合作为可替换的商业 `CompanyLookupSource`，不能当作无条件公共来源。

## 3. 国家企业信用信息公示系统

### 3.1 公众网站是查询服务，不是公开 API

国家企业信用信息公示系统的[官方使用帮助](https://bt.gsxt.gov.cn/affiche-query-info-help-660000.html)只说明公众输入企业名称或统一社会信用代码进行查询，名称支持关键词模糊查询，一次最多显示 100 条记录。市场监管总局还说明自 2021 年起公众查询实施[实名注册、登录和实名查询](https://www.samr.gov.cn/xw/zj/art/2023/art_e99bd2ba2c374ae5831d18b50b48f6e8.html)，改造原因之一是防范爬虫并保障数据安全。

由此能确认的是“人可以登录网页查询已知企业”，不能确认：

- 普通开发者可申请全国企业查询 API；
- 网页查询接口允许程序化调用；
- 可以按地图边界、经纬度或园区批量发现企业；
- 可以获得稳定分页、SLA、频率配额和机器调用凭证。

所以不能把浏览器中的网络请求逆向包装成 Adapter，也不能把网页一次显示 100 条理解成一个受支持的批量 API。

### 3.2 官方确有数据接口，但对象不是普通开发者

市场监管部门的[公示系统使用运行管理办法](https://www.samr.gov.cn/xyjgs/flfg/art/2023/art_f6972d9dbbf641168e71fab9de31cb7a.html)明确提到数据接口和批量导出，但其直接服务对象是网络市场监管信息化系统和其他政府部门；开放本辖区企业信用信息需要审批，跨辖区开放还需上级批准。系统使用授权也由市场监管总局和省级部门面向国务院部门、地方政府部门管理。

市场监管总局 2024 年的[官方发布会](https://www.samr.gov.cn/xw/xwfbt/art/2024/art_9b77c1d454f943c799e1bd4a4ee15ae6.html)称接口调用主要服务协同监管，并正在部分地区试点向平台企业开放共享信用监管数据。这说明企业侧开放仍是特定试点/合作，而不是已有统一申请入口的全国公众 API。

因此，国家公示系统目前不能实现 Job Atlas 的正式 Adapter。若未来取得市场监管部门的数据共享授权，应把它视为新增的受审批来源，而不是继续抓取公众网页。

## 4. 地方政府开放数据平台

地方平台可能提供真正的机器接口，但必须逐个目录核验，不能用“政府已经开放数据”的政策表述代替可用性验证。

- 福州市政府的[公共数据开放管理办法](https://www.fuzhou.gov.cn/zfxxgkzl/szfbmjxsqxxgk/szfbmxxgk/fzsrmzf/zc/gfxwj/201911/t20191115_3083181.htm)把数据分为普遍开放和授权开放；授权开放需提交用途、场景和安全措施，商业开发还可能需要公开竞争，且超出授权场景可被关闭访问权限。
- 福州市 2021 年[公共数据开放工作计划](https://sjglj.fuzhou.gov.cn/zwgk/fgwj/202105/t20210511_4096118.htm)把企业注册登记类数据列为开放重点，但这只是工作计划；本次没有从当前官方目录确认到可直接调用、字段与授权均明确的福州企业注册 API。因此，福州企业数据接口的**当前可用性未知**。
- 地方正式 API 的确存在。例如天津市政府开放平台的[“企业基本信息-开放”目录](https://open.data.tj.gov.cn/sjjk/0bbd9b575fb94d47b5fbd0d8c6faea27.htm)列出企业名称、统一社会信用代码、企业类型、成立日期、法定代表人等字段，但标为“有条件开放”，需要申请。这只能证明地方政府平台可按目录提供企业数据，不能证明福州、长沙或其他城市具有同一数据集与权限。

截至本次核验，没有从长沙市或湖南省当前官方目录确认到一个允许 Job Atlas 申请并稳定调用的企业注册信息 API；该能力标记为 **unknown**，不能计入第一版扫描范围。

## 5. Job Atlas 的设计落点

### 5.1 Adapter 归属

企查查、天眼查和获批的地方企业数据都应隐藏在 `RegionalCompanyDiscovery` 内部的 `CompanyLookupSource` Seam 中：输入已经从地图发现的企业候选，输出经过补全的 `CompanyInfo`。它们不是新的业务模块，也不改变现有三个深模块。

当前没有一个被核验的商业或政府企业数据来源，能够实现具有地图范围完成性的 `AreaCompanySource`。关键词搜索可以作为内部线索召回，但不能把“没有更多搜索结果”解释成“区域内企业已经扫描完成”。

### 5.2 第一版来源分级

1. **默认必扫：无新增来源。** 本次调查没有发现可无条件纳入第一版的企业数据 Adapter。
2. **可选增强：企查查或天眼查的已知企业核验。** 只有在项目主体完成认证、应用场景审核/购买，并确认数据保存和使用合同后才能启用；建议二选一，不需要同时购买。
3. **逐城市可选：地方政府开放数据。** 只有当具体目录仍在线、申请获批、字段/更新频率/分页边界/许可已验证后，才为该城市实现 Adapter。
4. **需政府合作：国家公示系统数据接口。** 在取得正式共享授权前不实现。
5. **禁止替代方案：抓取企查查、天眼查或国家公示系统的人类网页。** 官方 API 或正式开放数据不可用时，应明确来源不可用，而不是绕过授权。

### 5.3 对 `completed / blocked` 的影响

来源配置采用二态即可，不引入含糊的“尽力而为”：

- 未购买、未获批或尚未验证的企业数据来源处于**未启用**状态，不属于该次任务声明的扫描范围，不影响 `completed`。
- 一个来源只有在凭证、授权、额度和可扫描边界全部验证后才能被**启用**。启用后就是该运行的必扫来源；调用失败先自动重试，仍未完成则整个任务 `blocked`，不能静默降级成“没有企业”。
- 额度耗尽、认证失效、应用场景未获批、合同不允许当前用途，属于无法靠原样自动重试解决的问题；工作项记 `error` 和具体 `reason`，等待配置修复后由 `RestartDiscovery` 继续。
- 关键词搜索返回零结果只是该查询的结果，不能证明地图区域完成；只有拥有明确范围和终止条件的 `AreaCompanySource` 完成后，第一模块才可以报告区域扫描完成。

这个边界允许第一版先运行，不把尚未签约或尚未开放的来源变成永久阻塞点；以后接入商业或地方政府数据时，也不需要修改三个业务深模块以及对外 `Start / Get / Restart` Interface。
