# Domain docs

工程技能探索本仓库前，应按以下规则读取领域文档。

## 开始探索前

- 读取根目录的 `CONTEXT.md`
- 读取 `docs/adr/` 中与当前工作相关的 ADR
- 如果文件不存在，直接继续，无需提前建议创建

## 文件布局

本仓库采用单领域布局：

```text
/
├── CONTEXT.md
└── docs/
    └── adr/
```

## 使用领域词汇

议题标题、规格、重构方案、假设和测试名称应使用 `CONTEXT.md` 定义的领域词汇，避免使用其中明确排除的同义词。

如果需要的概念尚未定义，应先判断这是错误用词还是领域模型确实存在空缺；真实空缺交由 `domain-modeling` 处理。

## 标记 ADR 冲突

如果后续方案与既有 ADR 冲突，应明确指出冲突及重新讨论的原因，不得静默覆盖既有决策。
